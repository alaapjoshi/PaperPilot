What's in the repo

Every folder, and why it's there

src/App.tsx

The whole app: take a picture, then the Play, Game, CAD and Hands tabs.

one screen, all input routing

src/lib/

The engine: tap detection, outline tracing, hand tracking, gestures, audio and synthesized instruments.

tap · regions · tracking · gesture · audio · synth (+ tests)

src/components/

The 3D views and the game: the CAD bracket, the hand-controlled cube and Paper Dash.

CadStage · CubeStage · DashGame

server/

The Gemini scan route. Keeps the API key off the browser and tracks how much each scan costs.

identify.ts → POST /api/identify

public/

Bundled hand-tracking model and piano and drum samples, so it plays offline.

models/ · audio/

docs/

Dev notes, audio licenses, a sample drawing to try, and these README images.

DEVELOPMENT.md · sample/ · images/

scripts/run.mjs

One launcher behind npm run dev, build, preview and test.
